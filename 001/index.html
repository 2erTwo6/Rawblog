这是 Rawblog 的第一篇文章，顺便把这个博客的全部哲学写清楚：

  • 一篇博客一个文件夹 —— 001/、002/、003/……编号只增不减；
  • 每个文件夹里只有一个 index.html，链接时写 001/ 即可，不用带文件名；
  • NoBuild —— 没有 Markdown、没有模板引擎、没有 package.json。写 HTML 就是写博客；
  • 新文章 = 复制上一个文件夹 → 编号 +1 → 改内容 → 去首页列表加一行链接。完事。

目录长这样：

├── 001/
│   └── index.html   ← 本文
├── 002/             ← 下一篇
│   └── index.html
├── index.html       ← 首页（文章列表）
└── style.css        ← 唯一的样式表

就这些。剩下的交给浏览器。
